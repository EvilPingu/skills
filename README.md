# Skills

Sammlung von Skills für [Claude Code](https://claude.com/claude-code). Jeder Unterordner ist ein eigenständiger Skill mit `SKILL.md`, Skripten und eigener Beschreibung.

| Skill | Zweck |
|---|---|
| [anno117-spielstand](anno117-spielstand/) | Anno-117-Spielstände lesen und bearbeiten |
| [claude-code-sandbox](claude-code-sandbox/) | Claude Code unter einem eingeschränkten Windows-Nutzer betreiben |

## Einbinden

Den Ordner eines Skills nach `~/.claude/skills/` kopieren oder dorthin verlinken, z. B. unter Windows:

```
mklink /J "%USERPROFILE%\.claude\skills\anno117-spielstand" "<Repo>\anno117-spielstand"
```
